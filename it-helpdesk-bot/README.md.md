# 🤖 IT Helpdesk Telegram Bot

မြန်မာဘာသာဖြင့် IT ပြဿနာများကို ဖြေရှင်းပေးသော Telegram Bot
Groq AI (အခမဲ့) ကို အသုံးပြုထားသည်။

## ✨ Features

- 💻 ကွန်ပျူတာ / Laptop ပြဿနာ ဖြေရှင်းခြင်း
- 🌐 WiFi / Internet ပြဿနာ
- 🖨️ Printer / Scanner ချိတ်ဆက်ခြင်း
- 📧 Email / Password ပြဿနာ
- 🛠️ Software Install / Error ဖြေရှင်းခြင်း
- 💬 မြန်မာဘာသာဖြင့် ဖြေကြားခြင်း
