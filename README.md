# it-helpdesk-bot
🤖 IT Helpdesk Telegram Bot  မြန်မာဘာသာဖြင့် IT ပြဿနာများကို ဖြေရှင်းပေးသော Telegram Bot

Checklist
□ .env file ဖန်တီးပြီး API Key များ ထည့်ပြီး
□ .env.example ဖန်တီးပြီး
□ .gitignore ဖန်တီးပြီး (.env ပါကြောင်း သေချာ)
□ it_bot_v2.py ကို os.getenv() သုံးဖို့ ပြင်ပြီး
□ requirements.txt ဖန်တီးပြီး
□ README.md ဖန်တီးပြီး
□ GitHub repo ဖန်တီးပြီး
□ git init → git add . → git commit → git push လုပ်ပြီး
□ GitHub မှာ .env မပါကြောင်း စစ်ပြီး
